# Исправление распознавания матчей

Изменения в `bot.py`:

- Ответ кнопки «Получить игроков» привязывается к номеру матча и, когда Discord предоставляет данные, к исходному сообщению.
- Для карточек «на проверку» анализируется только исходный игровой скриншот, а не изображения из ответа кнопки.
- Добавлен отдельный строгий режим распознавания табло STANDOFF 2.
- Исправлен новый формат карточки, где в «Команда A/B» есть только строки `#ID ник`, а окно «Получить игроков» возвращает нулевые K/A/D.
- Для такого формата кнопка «Получить игроков» не нажимается: ID и ники берутся прямо из Команды A/B в карточке, а счёт, стороны CT/T и K/A/D — из исходного скриншота.
- Счёт копируется слева направо без прибавления завершившегося/следующего раунда.
- Учтён столбец «Деньги» перед У/П/С у команды атаки.
- ID берутся из окна игроков, но K/A/D и счёт — из исходного скриншота.
- Команды и игроки сопоставляются по никам; при неоднозначности регистрация отменяется.
- Бот не отправляет `=g`, если уверенность распознавания ниже 0.90.

## Рекомендуемые переменные Railway для первого теста

```env
PROCESS_CONCURRENCY=1
GEMINI_MAX_RETRIES=1
```

После нескольких успешных матчей можно увеличить значения. Не загружайте `.env` с реальными токенами в GitHub.

- Добавлена команда `забыть <номер>` для удаления одной игры из памяти через Discord.
- Дубликаты одной игры больше не мешают обработке: регистрируется одна карточка, а после ответа `Готово` все карточки с тем же номером матча удаляются из канала.
- Если матч уже есть в сохранённой статистике регистраций, его повторные карточки удаляются без повторной команды `=g`.
- Если обработка единственной активной копии завершилась ошибкой, оставшиеся дубли не считаются навсегда просмотренными и повторяются при следующем `старт`.
- Табло с четырьмя игроками на одной стороне теперь принимается: отсутствующий пятый игрок определяется по карточке и регистрируется как `0 0 13`.
- Разделены два формата: готовая карточка `внесён` сохраняет свои K/A/D, а карточка `на проверку` получает K/A/D со скриншота.
- Исправлено распознавание русских заголовков `К/А/С` в готовых карточках — они больше не попадают ошибочно в режим пустых ID/ников.
- `0 0 13` назначается только игроку без совпадающего ника на скриншоте (игрок отсутствует или на табло указан другой ник). Статистика остальных игроков не заменяется.
- Поддержаны две отсутствующие строки на одной стороне: табло 5×3 теперь регистрируется, а оба отсутствующих игрока получают `0 0 13`.
- После успешной регистрации автоматически удаляется сообщение регистрационного бота `Готово — Матч #... закрыт`. Ошибки `Не вышло` остаются в канале.
- Добавлена команда `удалить рег соо`: она просматривает полную историю всех обычных и приоритетных каналов регистрации и удаляет старые сообщения формата `Готово — Матч #... закрыт со счётом...`.
- Минимум снижен до шести надёжно сопоставленных игроков суммарно. Остальные игроки карточки получают `0 0 13`; требуется хотя бы одно совпадение с каждой стороны.
- Команда `бот ты тут?` показывает готовность, активность авторега, пользователя из `MY_ACCOUNT_ID`, текущую Discord-сессию, статистику и конфигурацию без секретов, а также прикладывает HTML-отчёт.
- Ограничение команд по `MY_ACCOUNT_ID` удалено: `старт`, `енд`, `стата`, `забыть`, очистка сообщений и проверка статуса доступны всем пользователям.
- Пересланные карточки вне активных каналов регистрации распознаются как тестовые и получают в ответ только готовое сообщение `=g`.
- Тестовые пересылки не сохраняются в статистике, не ожидают `Готово` и не удаляются.
- Алгоритмы распознавания карточек, скриншотов, ников, счёта и K/A/D не изменены.
- После успешной регистрации в лог отправляется исходная карточка игры: сначала настоящей пересылкой, а при недоступности пересылки — резервной копией с текстом и изображениями.
- Исходная карточка копируется в лог до автоматического удаления из канала регистрации.
