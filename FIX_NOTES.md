# Исправление распознавания матчей

Изменения в `bot.py`:

- Ответ кнопки «Получить игроков» привязывается к номеру матча и, когда Discord предоставляет данные, к исходному сообщению.
- Для карточек «на проверку» анализируется только исходный игровой скриншот, а не изображения из ответа кнопки.
- Добавлен отдельный строгий режим распознавания табло STANDOFF 2.
- Счёт копируется слева направо без прибавления завершившегося/следующего раунда.
- Учтён столбец «Деньги» перед У/П/С у команды атаки.
- ID берутся из окна игроков, но K/A/D и счёт — из исходного скриншота.
- Команды и игроки сопоставляются по никам; при неоднозначности регистрация отменяется.
- Бот не отправляет `=g`, если уверенность распознавания ниже 0.90.

## Рекомендуемые переменные Railway для первого теста

```env
PROCESS_CONCURRENCY=1
GEMINI_MAX_RETRIES=1
```

После нескольких успешных матчей можно увеличить значения. Не загружайте `.env` с реальными токенами в GitHub.

- Добавлена команда `забыть <номер>` для удаления одной игры из памяти через Discord.
