# DOMINION FACEIT — Railway

## Загрузка

1. Распакуйте архив в репозиторий GitHub или загрузите содержимое проекта в Railway.
2. В Railway добавьте переменные из `.env.example`.
3. Обязательно задайте `DISCORD_TOKEN`, `GUILD_ID` и `GEMINI_API_KEY`.
4. Команда запуска уже указана в `railway.json`: `python bot.py`.

## Изменения ELO

- В канале регистрации игр показывается ELO для команд A и B.
- До подтверждения результата доступна кнопка **Изменить ELO**.
- После завершения матча ELO можно исправить кнопкой **Изменить ELO** в карточке матча.
- В панели администратора добавлена кнопка **ELO матча**.
- При изменении ELO завершённого матча рейтинг всех десяти участников пересчитывается на разницу между старым и новым начислением.
- При восстановлении профиля сохранённый ELO больше не сбрасывается до 1000.

База SQLite обновляется автоматически при запуске: существующие данные сохраняются, а новые поля ELO добавляются миграцией.
